## ⚡ The Problem: Why AI-Generated Code Fails in Production

AI code generation models are remarkably proficient at implementing business logic and making happy-path unit tests pass. However, when deployed into real-world production environments, AI-generated services routinely collapse under stress due to:

1. **Hidden Race Conditions:** Non-atomic balance updates, counter increments, and missing database row locks (`SELECT FOR UPDATE`) or in-memory synchronization primitives (`asyncio.Lock`), leading to silent state corruption, duplicate orders, or double-spending.
2. **Missing Input Validation & Unhandled Crashes:** Naive payload parsing (`data = json.loads(...)`, `amount = data['amount']`) without schema validation. This triggers unhandled `500 Internal Server Error` crashes on malformed inputs or, conversely, **silently swallows** invalid data with `200 OK`.
3. **Fragile Socket Handling:** Client connection drops, half-open sockets, and unexpected TCP EOF errors causing worker thread starvation, hung event loops, or socket descriptor leaks.

`chaos-qa` is built to catch these vulnerabilities locally before code reaches staging or production.

## 🚀 Key Capabilities

- **🏎️ Race Condition Hammer (`asyncio.Barrier`):**
  Synchronizes a burst of 20–50+ identical requests down to the exact same millisecond using `asyncio.Barrier` and `httpx.AsyncClient`. Detects lost updates, state collisions, inconsistent mixed status codes (e.g. 200 vs 500), and latency spikes.

- **🧪 Multi-Vector Payload Fuzzer:**
  Automatically mutates JSON payloads across syntactic corruption, type confusion (strings for numbers, nulls, arrays for objects), boundary anomalies (negative numbers, giant 50KB strings, null-byte injections, formatting exploits). Classifies server behavior into:
  - `HANDLED_4XX`: Robust defensive error handling.
  - `CRASH_500`: Unhandled crash/exception in AI-generated code.
  - `SILENT_SWALLOW_200`: Insecure acceptance of invalid input without validation.

- **🔌 Socket Chaos & Unexpected EOF:**
  Directly opens raw TCP sockets via `asyncio.open_connection`, transmits incomplete/truncated HTTP headers and body fragments, and abruptly tears down connections. Verifies post-attack server availability and measures latency degradation.

- **🛡️ Resilience Score (0–100) & AI Remediation Engine:**
  Evaluates overall resilience, assigns an engineering rating (`A` through `F`), and outputs **concrete, actionable remediation instructions** tailored to fix AI-generated code.

## 📦 Cross-Platform Quickstart

`chaos-qa` is fully cross-platform and runs natively on macOS, Linux, and Windows with Python 3.14+.

### macOS & Linux

```bash
# 1. Clone repository
git clone https://github.com/your-username/chaos-qa.git
cd chaos-qa

# 2. Create and activate virtual environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies in editable mode
pip install -e .

# 4. Run tests
pytest -v
```

### Windows (PowerShell)

```powershell
# 1. Clone repository
git clone https://github.com/your-username/chaos-qa.git
cd chaos-qa

# 2. Create and activate virtual environment
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1

# 3. Install dependencies in editable mode
pip install -e .

# 4. Run tests
pytest -v
```

## 💻 CLI Usage

You can run commands using the installed entry point `chaos-qa` or directly via Python module `python -m src.cli`.

### 1. Full Chaos Test Suite (`attack`)
Executes all vectors (race condition hammer, payload fuzzer, and TCP socket disruption) and produces the resilience evaluation report.

```bash
python -m src.cli attack http://127.0.0.1:8000/api/withdraw \
  --method POST \
  --concurrency 25 \
  --json '{"amount": 50, "account_id": "acc-42"}'
```

*Output includes Rich tables detailing each attack phase, an ASCII Health Gauge, Resilience Score, and prioritized remediation steps.*

### 2. Targeted Race Condition Strike (`race`)
Fires concurrent requests synchronized by `asyncio.Barrier` to stress test state atomicity.

```bash
python -m src.cli race http://127.0.0.1:8000/api/transfer \
  --method POST \
  --concurrency 30 \
  --json '{"recipient": "bob", "amount": 100}'
```

### 3. Payload Fuzzing (`fuzz`)
Mutates input data into broken JSON, illegal types, negative numbers, and boundary values.

```bash
python -m src.cli fuzz http://127.0.0.1:8000/api/order \
  --method POST \
  --json '{"item_id": "sku-001", "quantity": 2}'
```
